# Métriques Dashboard IA — SénSanté

## Objectif

Le dashboard IA permettra de visualiser les statistiques générées par les consultations et les diagnostics IA.

---

# Métriques proposées

## 1. Nombre total de consultations

Permet de suivre l’activité globale.

## 2. Nombre de diagnostics IA générés

Permet de mesurer l’utilisation de l’intelligence artificielle.

## 3. Répartition des urgences

- Faible
- Moyen
- Urgent

## 4. Taux moyen de confiance IA

Moyenne des scores de confiance retournés par Groq.

## 5. Répartition par région

- Dakar
- Thiès
- Saint-Louis
- Kaolack

## 6. Symptômes les plus fréquents

- Fièvre
- Toux
- Fatigue

## 7. Diagnostics les plus fréquents

- Suspicion paludisme
- Dengue
- Infection respiratoire

---

# Visualisations recommandées

- Cartes statistiques
- Graphiques
- Camemberts
- Courbes

---

# Technologies possibles

- Recharts
- Chart.js
- Tremor

---

# Objectif final

Aider les agents de santé à :
- détecter les tendances,
- suivre les urgences,
- améliorer le suivi médical communautaire.
